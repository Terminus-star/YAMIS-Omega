# YAMIS Mass Effect Omega

A recolour fork of [**yet-another-monochrome-icon-set (YAMIS)**](https://bitbucket.org/dirn-typo/yet-another-monochrome-icon-set)
by Dirn, licensed GPL-3.0 (see `LICENSE`, `Authors`, `changelog`, kept unchanged from upstream).

Every icon that used YAMIS's own `currentColor` convention is recoloured with a vertical gradient
in the Mass Effect Omega (ME2) palette instead of a flat colour, and a couple of extra app icons not
covered upstream are added. Full details, exactly what changed and how, are in
[`NOTICE-MassEffect.md`](NOTICE-MassEffect.md).

This fork was generated by [`theme/gen_icons.py`](https://github.com/Terminus-star/mass-effect-hud/blob/master/theme/gen_icons.py)
in the [mass-effect-hud](https://github.com/Terminus-star/mass-effect-hud) project, which also has
a matching Kvantum theme, Plasma Style and KDE colour scheme.

See also: **YAMIS Mass Effect Citadel**, the ME1 palette counterpart.

## Install

Copy this repository into `~/.local/share/icons/YAMIS-Omega` (or wherever your distro's icon theme
directory is) and select "Mass Effect Omega" in your desktop's icon settings.
